## 更新方法

1. 在手机上截屏（或 `screencap`），压缩为 JPG（建议单张 < 300KB，仓库体积友好）
2. 覆盖本目录同名文件（或新增并同步改 `README.md` 预览区的表格）
3. 提交上传

> 当前截图对应 **v1.2.0（2026-08-17）** 界面；v1.3.x 侧栏改造（三条杠 + 浮层侧栏）后的新截图待更新。
